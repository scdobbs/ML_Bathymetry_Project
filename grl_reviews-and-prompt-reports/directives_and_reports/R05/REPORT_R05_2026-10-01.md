## 2. Challenge clause

1. **§2.2.4 "≥ 10 tiles with a finite target and a finite prediction", applied "at tile and block scale".** The bar's prediction tables hold one scale each, so a block table carries no tile rows from which to count. Implemented as: the eligible-pair set is computed once per target from the tile table (finite target; GBT predictions are always finite, reference rows are NaN where undefined so they are checked per predictor on the tile rows) and the detection set once from the block table, then passed explicitly to every `score_one` / `compare` / `median_ci` call (`elig_pairs`, `det_pairs`); when not passed, `eval_v1_1` computes them from the table it is given. Both sets are saved in `bar/pair_rules.json`.
